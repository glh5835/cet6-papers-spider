# 大学英语六级真题 PDF 爬虫（2023–2026）

自动批量下载 2023 年 6 月至 2026 年 6 月全国大学英语六级（CET-6）真题试卷 PDF，
按 `年份/月份/第X套.pdf` 目录结构保存。

## 数据源

[catteacher0515/cet6-download](https://catteacher0515.github.io/cet6-download/)
——纯静态 GitHub Pages 站点，无需登录，PDF 直链下载（截至 2026-09 已收录 2021–2025 全部 30 套；
2026 年 6 月真题考后约 1–2 周上线，届时重跑脚本即可自动补齐）。

## 安装与运行

```bash
pip install -r requirements.txt

# 爬取默认范围 2023–2026
python main.py

# 指定年份范围
python main.py --start 2023 --end 2026

# 指定保存目录
python main.py --save-dir "D:\LEGION D\Documents\英语6级"
```

## 项目结构

| 文件 | 职责 |
|------|------|
| `config.py` | 配置：数据源、保存路径、请求头、超时/重试、频率控制 |
| `parser.py` | 解析器：提取 PDF 链接，解析年份/月份/套数元数据 |
| `spider.py` | 主逻辑：协调解析与下载，过滤未来场次 |
| `downloader.py` | 下载器：断点续传、完整性校验、并发下载 |
| `spider_utils.py` | 通用工具：带重试的 GET、随机延时、未来场次判断 |
| `main.py` | 入口：命令行参数、日志配置 |

## 关键特性

- **断点续传**：中断后重跑，`.part` 半成品文件从断点继续，无需重新下载
- **自动跳过**：已下载完成的文件自动跳过，可反复运行
- **完整性校验**：校验 Content-Type/魔数与最小体积，避免把错误页存成 PDF
- **并发下载**：3 线程并发，线程内随机延时 1–2 秒控制请求频率
- **重试机制**：网络失败最多重试 3 次（线性退避 2s/4s），连接 10s / 读取 30s 超时
- **未来场次**：自动跳过尚未举行的考试（如 2026 年 12 月）
- **日志**：控制台 + `cet6_spider.log` 文件双输出

## 注意事项

- 仅用于个人学习研究，请遵守目标网站服务条款，勿用于商业用途
- 请勿调大并发数或调小延时，避免给站点造成压力
- 本站无听力音频；如需听力可在新东方在线（cet6.koolearn.com）等平台获取
